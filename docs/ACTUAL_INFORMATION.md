# 실제 SEC 재무·13F·Alpaca 뉴스 연결

2026-11-25 KST. 기존 SEC User-Agent와 이미 허가된 Alpaca 연결을 사용합니다. 새 유료 제공업체·LLM·SNS 키는 추가하지 않았습니다. 실제 자료가 없으면 `missing/unavailable/null`을 반환합니다. 기존 DemoProvider는 별도 데모 실행에만 남아 있으며 실제 정보 입력으로 사용하지 않습니다.

## 1. 재무·TTM·팩터

SEC CompanyFacts와 Submissions를 수집합니다. 10-K/10-Q의 실제 접수 시각과 수집·분석 시각을 기록합니다. 접수 시각이 없는 오래된 항목은 공시일의 뉴욕 자정이 지난 후로 보수적으로 처리합니다. 해당 수집본보다 이른 `as_of`에는 자료를 반환하지 않습니다.

- USD 손익·현금흐름: 실제 단독 분기 또는 동일 회계연도 시작일의 누적 금액 차이로 분기를 계산합니다. 연속 4개 분기만 TTM으로 합칩니다. 53주 회계연도를 허용합니다.
- 대차대조표: 같은 결산일에 실제 보고된 값만 사용합니다. 총 이자부채가 확인되지 않으면 장기부채를 총부채로 바꾸거나 단기차입을 0으로 두지 않습니다.
- EPS: 분기 EPS가 모두 있는 경우에만 합칩니다. 가중평균 주식 수의 영향을 받는 EPS 누적 값을 단순 차감하지 않습니다. 현재 4개 회사의 비교 EPS와 일부 부채·이자 지표는 미확보 상태입니다.
- 실제 계산 가능 지표: AAPL 13/17, MSFT 12/17, NVDA 12/17, TSLA 12/17. 나머지는 null입니다. SPY는 회사 재무로 대체하지 않습니다.
- 팩터: 가치(자본/추정 시가총액), 12–1개월 모멘텀, 질(ROE), 성장(TTM 매출 YoY), 저변동성(63일), 유동성(20일 IEX 거래대금). 선택 팩터가 모두 있는 4개 회사의 단면 순위만 계산합니다. 시가총액 추정은 최근 정규장 종가 × 관측한 보통주 발행주식 수이며 150일 초과 주식 수는 제외합니다. EPS용 가중평균 주식 수를 사용하지 않습니다.
- 실제 GICS 데이터가 없어 섹터 중립화는 unavailable입니다. SIC 기반 프로젝트 리스크 그룹으로 GICS를 대신하지 않습니다. 4종목 순위는 미래 성과나 매수 확률을 뜻하지 않습니다.

## 2. 기관 13F

Berkshire Hathaway와 Vanguard Group의 최근 확보된 두 보고기간, 총 4개 13F-HR 원문을 공식 SEC archive에서 받았습니다. 표의 행 수와 가치 합계를 cover XML과 대조합니다. 2023-01-03 이후 제출 건은 USD, 그 이전 제출 건은 천 달러 단위를 적용합니다. 수정공시 RESTATEMENT와 NEW HOLDINGS를 구분하며, 추가 보유 수정에 원신고가 없으면 결과를 추정하지 않습니다.

| 신고 주체 | 최신 확보 보고기간 | 직전 보고기간 | 최신 표 행 수 | 상태 |
|---|---|---|---:|---|
| BERKSHIRE HATHAWAY INC | 2026-09-30 | 2026-06-30 | 89 | 조회 가능 |
| VANGUARD GROUP INC | 2025-12-31 | 2025-09-30 | 17,686 | 오래된 보고서 |

CUSIP은 실제 기존 기업행사 자료에 확인된 매핑만 사용합니다. 알 수 없는 종목은 미매핑 상태로 보존합니다. 보통주·옵션·원금 표기를 섞지 않고, 확인된 분할로 이전 주식 수를 보정한 뒤 신규·증가·감소·청산·유지를 계산합니다. 13F는 지연된 신고 보유량이며 현재 보유량, 기관 전체 NAV, 실제 매수 날짜·거래 가격이 아닙니다. BlackRock Finance 구 법인의 오래된 신고를 현재 BlackRock 보유량으로 표시하지 않습니다.

## 3. 뉴스 / 어닝콜

Alpaca News에서 지정 5종목 관련 실제 기사 **69건**을 확보했습니다. 최초 7일 범위, 페이지당 50개·한 번 최대 10페이지로 제한하고, 이후에는 2시간 중첩 구간을 갱신합니다. 동일 ID·수정 시각·본문 해시는 중복 저장하지 않으며 원래 사용 가능 시각을 유지합니다. 새 수정 버전에는 별도 시각을 기록합니다. 원문 응답과 본문은 비공개 로컬 저장소에 보관하고, 화면에는 제목·출처 링크·키워드·원문 수치만 제공합니다.

분석은 명시적인 정규식 기반 earnings/guidance/risk/capital 언급 및 수치 추출입니다. LLM 요약·감성·상승 확률로 표시하지 않습니다. 공식 어닝콜 녹취록과 허용 음성 수집, 전사, 분기 비교 LLM 분석은 연결되지 않아 unavailable입니다. 모의 녹취록·생성 기사·가상 감성 점수를 만들지 않습니다.

## 4. 기업행사 백테스트

기존 포트폴리오 원장의 분할 차단을 보완했습니다. 실제 효력일 장 시작에 정수 수량을 바꾸고 현금은 보존합니다. 당일 지정가 기준가격과 이전 거래량을 현재 주식 단위로 바꿉니다. 매매 신호에는 당시 이전 세션 자료만 사용합니다. 독립 현금·보유량·평가액 대사를 실행합니다.

실제 NVDA IEX 분봉 **33,946행 / 원본 4페이지**, 사전 84세션과 평가 10세션(2024-06-03–06-14)을 사용했습니다. 2024-06-10 10대 1 분할에서 **77→770주, 현금 조정 $0**를 확인했습니다. 지정가·체결 시각·원장 대사 모두 통과했습니다. 이 단일 종목/단일 슬롯 buy_hold 계산의 비용 차감 수익률은 **+12.726720%**, 최대 낙폭은 **−1.091090%**입니다. 분할 회계 검증 목적이며 현재 5종목 paper 전략의 성과와 다릅니다.

현재 계좌에 실제 종목변경·단주 현금 정산 사례가 없습니다. 새 티커 자동 이관·cash-in-lieu는 확인 없이 진행하지 않으며 기존 검토 차단을 유지합니다. 실제 입금 대신 가상 정산금을 만들지 않습니다.

기존 동일 입력 재실행: 252세션 리스크 적용 Momentum **−5.754559%**; 126세션 선택 전략 **−3.819483%**, 고정 Momentum60 **−3.513833%**. 주요 지표는 이전 결과와 동일합니다. 오늘 수집한 재무·13F·뉴스를 어제까지의 예측에 소급 반영하지 않았습니다. 뉴스·공시 추가 전후 예측 개선이나 5/15/60/180분 성과를 검증했다고 보고하지 않습니다.

## 자동 갱신과 실행

기존 5분 launchd 작업이 주문·리스크·실적 처리를 끝낸 뒤 독립 정보 작업을 실행합니다. 재무·13F는 24시간, 뉴스는 15분 TTL을 적용합니다. 실패 시 마지막 성공 저장본과 원래 수집 시각을 보존하고, 15분부터 최대 24시간까지 간격을 늘립니다. 정보 실패가 기존 매매 정지 상태를 해제하지 않습니다. `configs/information.json`의 `enabled`로 정보 갱신을 끌 수 있습니다.

```bash
.venv/bin/python scripts/collect_information.py --env-file /authorized/path/.env
.venv/bin/python scripts/validate_actual_information.py
.venv/bin/python scripts/validate_actual_split.py --env-file /authorized/path/.env
```

API는 키 없이 검증된 로컬 저장본만 읽습니다. `GET /api/assets/{symbol}/fundamentals?as_of=...`, `/api/factors`, `/api/information?symbol=AAPL&as_of=...`를 사용합니다. 웹의 **기업·가치평가**, **팩터 리서치**, **뉴스·기관 공시**에서 확인합니다. 외부 키는 기존 Alpaca 설정과 로컬 `.env`의 `SEC_USER_AGENT`만 필요합니다. 원문·이메일·비밀키·브로커 식별자는 Git에 추가하지 않습니다.

## 한계와 다음 작업

- 현재 정보 관측을 앞으로 축적한 후 시간 순서가 보장되는 이벤트 백테스트를 설계해야 합니다. 현재 과거 데이터만으로 신규 정보 변수의 효과를 주장하지 않습니다.
- 실제 GICS/과거 발행주식 수, 누락 재무 태그와 EPS/부채 분해, 기관 법인 변경 및 더 긴 수정공시 체인 확인이 필요합니다.
- 공식 IR 어닝콜 자료 제공/권한 확인과 분석 모델 연결이 필요합니다. 자동 전사·SNS·유료 외부 자료는 이번 작업에 포함하지 않았습니다.
- IEX는 단일 거래소 관측이며 정규장 외 반응·전체 시장 유동성·호가 대기열을 검증하지 않습니다.
